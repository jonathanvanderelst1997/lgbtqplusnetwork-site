# lgbtqplusnetwork.be

Website van **LGBTQ+ Network**, het platform van Think Different vzw.

- `site/`: de statische website (HTML + CSS, geen build, geen cookies, geen trackers).
- `render.yaml`: Render Blueprint (gratis static site, eigen domein, beveiligingsheaders en doorverwijzingen van de oude Wix-adressen).
- `TE-BEVESTIGEN.md`: wat de vzw nog moet nakijken of invullen.

Plekken die nog bevestigd moeten worden staan in de HTML als commentaar `<!-- [[TE BEVESTIGEN]] ... -->`.
Zet hier nooit persoonsgegevens van leden of hulpvragers: deze repo is publiek.
