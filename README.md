# lgbtqplusnetwork.be: doorverwijzing

Deze tak (`gh-pages`) is alleen de snelle doorverwijzing van lgbtqplusnetwork.be naar de
Wix-site van LGBTQ+ Network (Think Different vzw). De site zelf staat op Wix en wordt daar bewerkt.

- `index.html`: toont de Wix-site op het eigen adres; op een gsm in de juiste breedte (320 px, zoals Wix).
- `404.html`: dezelfde pagina, zodat een diepe link als `/contact-us` meteen die Wix-pagina opent.
- `CNAME`: het eigen domein voor GitHub Pages.

Zet hier nooit persoonsgegevens: deze repo is publiek.
